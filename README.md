Dodge Game
Description

Dodge Game is a simple action game built using HTML, CSS, and JavaScript. In this game, the player controls a character inside a game area and must avoid falling objects that drop from the top of the screen. The player uses the keyboard arrow keys to move left and right. Each time an object is successfully avoided, the player's score increases. If the player is hit by a falling object, they lose a life. The game ends when all lives are lost.

The goal of the game is to survive as long as possible and achieve the highest score.

This project was created as part of a coding hackathon and demonstrates basic game development concepts such as movement, collision detection, timers, scoring systems, and user input.

Features
Player movement using keyboard arrow keys
Falling enemies that spawn repeatedly
Collision detection between player and enemies
Score tracking system
Lives system
Game Over message when lives reach zero
Simple game interface
Runs directly in a web browser
Deployed online using GitHub Pages
How to Play
Open the game in your web browser.
Click inside the game area to activate keyboard controls.
Use the arrow keys to move the player.
Avoid the falling objects.
Try to survive as long as possible.
Watch your score increase as you dodge objects.
The game ends when you lose all your lives.
Controls
Left Arrow Key — Move player left
Right Arrow Key — Move player right
Game Rules
The player starts with 3 lives.
Enemies fall from the top of the screen.
If an enemy reaches the bottom without hitting the player:
The score increases by 1.
If an enemy hits the player:
The player loses 1 life.
When lives reach 0:
The game displays Game Over.

Download or clone the project files.
Make sure these files are in the same folder:
index.html

Double-click index.html.
The game will open in your web browser.

No additional software is required.
